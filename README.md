## 🌟 Overview

**SkillLearn** is a full-stack, AI-powered skill development platform that helps learners build and improve technical and soft skills through **personalized learning paths, AI-generated curricula, interactive challenges, progress tracking, XP, streaks, badges, and performance analytics.**

Instead of following a fixed learning path, SkillLearn uses AI to help create a more personalized learning experience based on the learner's selected skill.

> 🎯 **Goal:** Turn learning into a structured, measurable, and engaging experience.

---

Traditional learning platforms often provide the same content to every learner.
